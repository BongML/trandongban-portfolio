# Dong Ban Tran — portfolio

Static page built with Vite, plus one small Three.js network in the hero (`src/network.js`).
`npm run dev` to work on it, `npm run build` to produce `dist/`.

- All page copy is in `index.html`; styles are in `src/style.css`.
- Portrait: `public/photo.jpg`. Workflow images and the Verda demo: `public/flows/`.
